# Responsibility change extraction for AI agent security audits

Research code for **Evidence for AI Agent Security Audits: Responsibility Change Extraction from Documents** by Mithun Paul Saint-Germain. The scripts generate synthetic contracts and incident reports, predict which party's responsibility changes in each sentence, and score the predicted sentence–party links against the generator's labels. The experiments evaluate document evidence extraction. An agent runtime audit would additionally need action and authorization records.

## Setup

Use Python 3.11. The LLM runs use MLX on an Apple silicon Mac. The generation and scoring scripts run without loading an LLM. These versions describe the local environment used to check the archive. The first use of the coreference and LLM backends may download model weights.

```sh
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m spacy download en_core_web_sm
```

The LLM default is `mlx-community/Qwen2.5-14B-Instruct-4bit`. Coreference uses `sapienzanlp/maverick-mes-ontonotes`. The circuit backend requires a local copy of the lambeq Bobcat checkpoint, including its configuration, weights, tokenizer files, and grammar. Set `BOBCAT_MODEL_PATH` to the checkpoint directory or place it in `~/.cache/lambeq/bobcat`. The model files are separate from this repository. The upstream model download has a [reported availability issue](https://github.com/Quantinuum/lambeq/issues/257).

## Reproduce the experiments

Run the commands from the repository root. Use a fresh checkout to regenerate predictions and observe uncached timings. Each seed generates 100 contracts and 100 incident reports. The reference labels are generated by the template code.

### Exploratory set (seed 0)

```sh
python -m experiments.audit_trail.gen_docs --seed 0
python -m experiments.audit_trail.build_structures --backends surface coref discocirc
python -m experiments.audit_trail.run_methods --llm
python -m experiments.audit_trail.run_hybrid --variants hyb_doc hyb_sent
python -m experiments.audit_trail.analyze
```

### Confirmation set (seed 1)

```sh
python -m experiments.audit_trail.gen_docs --seed 1 --tag seed1
python -m experiments.audit_trail.build_structures --tag seed1 --backends surface coref discocirc
python -m experiments.audit_trail.run_methods --tag seed1 --llm --llm-v2
python -m experiments.audit_trail.run_hybrid --tag seed1 --variants hyb_sent hyb_sent_v2
python -m experiments.audit_trail.analyze --tag seed1
```

The structural pass proposes sentence–party pairs. The sentence-level hybrid groups those pairs by sentence and makes one call per candidate sentence, listing all of its candidate parties in the same prompt. The `v2` prompts share additional guidance on completion and on sentences mentioning several parties. The `hyb_sent_v2` template adds a short reminder after the candidate list.

## Outputs and checks

- `data/processed/audit/docs.jsonl` and `docs_seed1.jsonl` contain the generated documents and reference labels.
- `results/a4_audit/` and `results/a4_audit_seed1/` contain the prediction JSONL, summary and breakdown CSVs, paired bootstrap comparisons, and a Markdown report after running the pipeline.
- The generator should produce 4,366 sentences and 2,187 duty-changing sentences for seed 0, and 4,371 sentences and 2,263 duty-changing sentences for seed 1.
- The reported seed-1 micro-F1 was 0.732 for `llm_zs_v2` and 0.820 for `hyb_sent_v2`. The design and original results are recorded in [the experiment notes](docs/DESIGN_AUDIT_TRAIL.md).
- The analyzer expects predictions from at least one supported comparison pair. For a quick structural check, build `surface`, `coref`, and `discocirc` on a small tagged set, run `run_methods --methods surface_any coref_any dc_any` with that tag, then run the analyzer with the same tag.
